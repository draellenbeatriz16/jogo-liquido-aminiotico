# Caso Maria: o mistério do líquido amniótico

Jogo de detetive sobre análise de líquido amniótico.

## Como jogar
Abra `index.html` no navegador (dois cliques). Não precisa de servidor nem de internet; só as fontes pixeladas vêm da internet e, sem conexão, o jogo usa uma fonte padrão.

## Estrutura
- `index.html`: página e carregamento dos arquivos
- `css/style.css`: visual, temas claro/escuro e adaptação para celular, tablet, desktop e TV
- `js/data.js`: etapas, perguntas, respostas, pistas e suspeitos
- `js/sprites.js`: sprites pixel art (cenas, detetive e Maria)
- `js/game.js`: lógica do jogo

## Compatibilidade
Celulares, tablets, notebooks, projetores e TVs; Chrome, Edge, Firefox, Safari e navegadores de celular recentes. Funciona por toque, mouse e teclado (teclas A a D ou 1 a 4 escolhem a resposta). Respeita tema escuro e movimento reduzido.

## Publicar online
Envie a pasta inteira para GitHub Pages, Netlify ou Vercel.
